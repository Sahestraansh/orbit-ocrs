# Student actions required before the final Word report

The code, local database, CSV importer, reproducible test definitions, report draft,
and diagram source are prepared in this project. The following evidence must come
from the student because it depends on the student's accounts, visible computer,
and actual executed test session.

## Required information

Send these details before the final Word document is generated:

1. Student full name exactly as it must appear.
2. Registration number / university ID.
3. Course code and course title.
4. Faculty name.
5. Department, university, semester, and academic year.
6. Submission date.
7. Team member names and IDs, or confirmation that this is an individual project.
8. Final public/shared GitHub URL.
9. Final Google Drive demo-video URL.
10. Whether the institution requires a declaration, certificate, acknowledgement,
    abstract, list of figures, or list of tables before the supplied table of contents.

## Evidence only the student can produce

- Screenshots captured on the student's computer from the final run.
- A green Selenium IDE execution screenshot.
- JMeter configuration and Aggregate Report screenshots from the actual run.
- The GitHub repository after it is published from the student's account.
- A narrated demo video uploaded to the student's Drive.
- An incognito-window check proving the repository and video are accessible.

## Rules for trustworthy evidence

- Do not fabricate a screenshot or change a failed test to “Pass” in the report.
- Retest after every code or test change.
- Keep the browser clock and URL visible when practical.
- Never expose `.env.local`, secret keys, access tokens, or passwords.
- Use the filenames in `SCREENSHOT_CHECKLIST.md`; this makes Word assembly reliable.
- If the institution asks about AI/tool assistance, follow its disclosure policy.
